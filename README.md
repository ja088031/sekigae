# せきがえメーカー

小学校の学級で使う、席替えアプリです。単一のHTMLファイルだけで動きます。

## 公開ページ

https://ja088031.github.io/sekigae/

## 特徴

- **インストール不要**。ブラウザで開くだけで使えます
- **外部との通信なし**。データはすべて端末のブラウザ内（localStorage）に保存されます
- 児童の名簿がサーバーに送られることはありません

## できること

### 座席レイアウト
- プリセット（25〜35席）と、縦横の自由指定
- 空きマスをタップして席を増減
- 机の向きを1つずつ変更（上・右・下・左）。コの字型も組めます
- 班分けの色塗り（ドラッグ対応）
- 男子席・女子席の指定。市松（男女交互）などのパターンをまとめて設定できます

### 名簿
- 1行1人で貼り付けるだけ。上から順に出席番号になります
- 児童ごとに男女とフラグ（リーダー／学力上位／支援が必要／配慮／視力配慮）を設定

### スマート配置
次の条件を同時に満たす席を探します。

- これまで隣になった回数が少ない子どうしを優先
- 視力配慮の子は前のほうの列へ
- 隣にしない組み合わせを避ける
- 男女席の指定を守る
- フラグを持つ子が同じ班（2×2）に偏らないよう分散
- 前と同じ席になりにくくする

条件をすべて満たせない場合でも失敗せず、ずれが最も少ない配置を返します。

### 子ども画面
- カウントダウン → ルーレット → 発表
- 「いっせいに発表」と「ひとりずつ発表」の2種類
- 効果音・BGM、フォント7種、テーマカラー5種

### 記録
- 隣になった回数のランキング、相性マップ、まだ隣でない子、座席の使用回数
- 席替えの履歴（100件まで）。過去の配置に戻せます

## データについて

保存先は**ブラウザごと**です。次の点にご注意ください。

- 毎回同じブラウザで開いてください（ChromeとEdgeでは別のデータになります）
- 閲覧履歴やサイトデータを削除すると、保存内容も消えます

設定タブの「⬇ 書き出す」でJSONファイルとして保存できます。別の端末へ移すときや、
バックアップにお使いください。

## 動作環境

Chrome、Edge、Safari など。ChromeOS（Chromebook）でも動きます。
